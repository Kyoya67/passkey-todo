## CORS Preflightの修正

- 使用箇所：`backend/internal/middleware/cors.go`、`frontend/app.js`、`DESIGN.md`
- AIの利用内容：Networkログの`OPTIONS`リクエストとfetchのヘッダーを比較し、CORS許可メソッドと不要な`Content-Type`の問題を切り分けた
- 採用理由：ブラウザのPreflightを正しく処理し、GETで不要なPreflightを発生させないため
- 開発者による対応：Echoの許可メソッドへ`OPTIONS`を追加し、bodyがあるリクエストだけ`Content-Type: application/json`を付与した
- 検証方法：`node --check frontend/app.js`、`npm run format:check`、GitHub Actions、クラウドAPIのhealthとTODO操作を確認した
- 代表的なプロンプト（実際の相談内容を要約）：
  - 「ブラウザのNetworkログでGETとPreflightがPendingになっている。EchoのCORS設定とfetchのヘッダーを比較して修正して」
