# AI利用記録：PR #34

PR：[fix: grant Amplify deployment permissions to GitHub Actions](https://github.com/catechlounge/kyoya67-todo/pull/34)

## 利用モデル・ツール

- ツール：OpenAI Codex、AWS IAM、GitHub Actions、Terraform
- 利用目的：GitHub ActionsのCDによるAmplifyデプロイで発生したIAM権限エラーの原因調査と修正
- 最終的な要件解釈、AWS操作の実行判断、コード確認、検証は開発者が行う

## Amplifyデプロイ権限の修正

- 使用箇所：`infra/modules/iam/`、`infra/modules/amplify/`、`infra/aws.tf`
- AIの利用内容：`amplify:GetJob`の対象ARNが`deployments/*`ではなく`jobs/*`であることを整理し、GitHub Actions用IAMポリシーを修正した
- 採用理由：Amplify APIごとに異なるリソースARNを正しく指定し、必要最小限の権限にするため
- 開発者による対応：`CreateDeployment`・`StartDeployment`を`deployments/*`、`GetJob`を`jobs/*`へ分離し、mainブランチに限定した
- 検証方法：Terraformのformat、`git diff --check`、IAMポリシーと実際のAccessDeniedエラーの照合、Amplifyデプロイ結果の確認を行った
- 代表的なプロンプト（実際の相談内容を要約）：
  - 「AmplifyのCreateDeploymentは成功するがGetJobだけAccessDeniedになる。実際のARNとIAMポリシーを比較して、必要な権限を修正して」
